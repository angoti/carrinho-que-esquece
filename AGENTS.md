# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

# Safe areas

- Never import `SafeAreaView` from `react-native`; it is deprecated.
- Use `SafeAreaView` or `useSafeAreaInsets` from `react-native-safe-area-context` instead.
- When using safe-area-context, keep `SafeAreaProvider` at the application root.
